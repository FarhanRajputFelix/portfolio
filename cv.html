KIDO — agentic-AI learning platform for children

2026 · live · repo
  • 11 cooperating agents on a ReAct loop with tool-calling, an orchestrator, a contradiction-detection agent and a fallback-recovery agent; every run persists an explainable trace so a parent can ask why.
