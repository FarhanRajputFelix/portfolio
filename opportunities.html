Why this page exists

A list of ten of these circulates widely on LinkedIn. I checked all ten against the official pages. Four were wrong in ways that would waste a real application. One programme on it is not running at all this year. One is advertised to computer-science students by a department that has no computer-science faculty. One quotes a stipend the university has never published. One omits a minimum GPA that decides eligibility outright.

So this page shows the correction next to the entry, in yellow, with the quote that proves it. Believe the quote, not me — and click through before you apply, because programmes change and this page is only as fresh as the date on each card.

What this page is not

It does not search the internet. It is a hand-verified catalogue of recurring programmes — things with annual cycles and stable URLs, which is exactly the category a list can stay honest about. It does not crawl job boards and it does not claim to be complete.

The dates are the weak point. Deadlines marked "expect the same shape" are inferred from the previous cycle, and I have labelled them that way rather than presenting an inferred date as a fact. A daily job re-checks every source URL and flags any that break; that catches dead links, not silently edited deadlines. Click through before you commit.

The judgement of whether you specifically should apply is a separate tool — an agent that reads a posting against a CV and returns apply, caveat or skip. That one needs an API key, so it runs on your own machine rather than here. Source and setup.
